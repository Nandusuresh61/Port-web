# Developer Portfolio

A responsive, premium developer portfolio website built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Interactive UI/UX**: Built with Framer Motion for premium, smooth micro-animations.
- **Responsive Design**: Mobile-friendly layout using Tailwind CSS v4.
- **Sections**:
  - **Hero**: Engaging landing section with key highlights.
  - **About**: Personal profile and background summary.
  - **Skills**: Interactive showcase of technical competencies.
  - **Projects**: Highlights of key projects, details, and tech stacks.
  - **Timeline**: Chronological career/education timeline.
  - **Architecture**: Diagrammatic layout of the web architecture.
  - **Contact**: Functional contact form and channels.

## 🛠️ Tech Stack

- **Core**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide React (Icons)
- **Animations**: Framer Motion
- **Build Tool**: Vite

## 📦 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Nandusuresh61/Port-web.git
   cd Port-web
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

To start the local development server:
```bash
npm run dev
```

### Build & Preview

To build the application for production:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
